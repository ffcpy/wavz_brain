Wavz
Wavz is a music-based social discovery project built with Python and FastAPI. The idea behind the project is simple: connect a user’s Spotify account and identify, in real time, what they are currently listening to.
Instead of focusing only on playlists or recommendations generated by algorithms, Wavz explores music as a form of presence and identity.
At its current stage, the project already includes:
* Spotify OAuth authentication
* Real-time access to the user’s currently playing track
* Retrieval of Spotify profile information
* Structured API responses
* Timestamped user listening status
Tech Stack
* Python
* FastAPI
* Spotify Web API
* OAuth 2.0
Current Endpoints
/login

Starts the Spotify authentication flow.
/callback

Receives the Spotify authorization code and generates the access token.
/musica_atual

Returns the user’s currently playing track.
/me

Returns basic Spotify profile information from the authenticated user.
/wavz-status

Combines user identity and current track information into a single structured response.
Example Response
{
  "usuario": "Felipi",
  "musica": "Time",
  "artista": "Pink Floyd",
  "timestamp": "15/05/2026 20:31:55"
}

Wavz
O Wavz é um projeto de descoberta social baseada em música, desenvolvido com Python e FastAPI. A ideia central do projeto é simples: conectar a conta do usuário ao Spotify e identificar, em tempo real, o que ele está ouvindo naquele momento.
Em vez de focar apenas em playlists ou recomendações geradas por algoritmos, o Wavz explora a música como uma forma de presença e identidade.
Atualmente, o projeto já possui:
* Autenticação OAuth com Spotify
* Acesso em tempo real à música reproduzida pelo usuário
* Recuperação das informações de perfil do Spotify
* Respostas organizadas da API
* Status musical do usuário com timestamp
Tecnologias Utilizadas
* Python
* FastAPI
* Spotify Web API
* OAuth 2.0
Endpoints Atuais
/login
Inicia o fluxo de autenticação com o Spotify.
/callback
Recebe o código de autorização do Spotify e gera o access token.
/musica_atual
Retorna a música que o usuário está ouvindo no momento.
/me
Retorna informações básicas do perfil Spotify do usuário autenticado.
/wavz-status
Combina informações do usuário e da música atual em uma única resposta estruturada.
Exemplo de Resposta
{
  "usuario": "Felipi",
  "musica": "Time",
  "artista": "Pink Floyd",
  "timestamp": "15/05/2026 20:31:55"
}
